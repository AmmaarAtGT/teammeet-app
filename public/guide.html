📱 How the Mobile Voice & Screen Lock Fix Works

Mobile operating systems (iOS and Android) aggressively throttle WebRTC audio and pause JavaScript timers when the device screen locks. TeamMeet implements a 3-layer anti-sleep defense:

1. WakeLock API

Requests `screen` wake lock to keep display active during call

→

2. Silent Audio Oscillator

Plays inaudible 40Hz sound to keep mobile audio engine awake

→

3. Visibility Observer

Automatically triggers `.play()` on all remote audio tracks upon app resume

// Core Keepalive snippet inside public/app.js: const audioCtx = new (window.AudioContext || window.webkitAudioContext)(); const osc = audioCtx.createOscillator(); const gain = audioCtx.createGain(); gain.gain.value = 0.0001; // Inaudible osc.connect(gain); gain.connect(audioCtx.destination); osc.start();
